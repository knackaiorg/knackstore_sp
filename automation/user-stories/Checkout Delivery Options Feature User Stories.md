# **User Stories**

## **US-1**

**As a customer,**  
 I want to choose from multiple delivery options  
 so that I can balance delivery speed and cost.

### **Acceptance Criteria**

* Three delivery options are displayed.  
* Customer selects one option.  
* Selection is mandatory before payment.

---

## **US-2**

**As a customer,**  
 I want to see delivery charges separately  
 so that I understand what I'm paying for.

### **Acceptance Criteria**

* Delivery fee appears as a separate line item.  
* Total updates after selection.

---

## **US-3**

**As a customer,**  
 I want to see the estimated delivery date  
 so that I know when my order will arrive.

### **Acceptance Criteria**

* Date updates based on selected option.  
* Weekends are excluded.  
* Cutoff rules are applied.

---

## **US-4**

**As a customer,**  
 I want my selected delivery option to appear in Order Confirmation and Order History  
 so that I can refer to it later.

### **Acceptance Criteria**

Display:

* Delivery Option  
* Delivery Fee  
* Estimated Delivery Date

---

## **US-5**

**As a customer,**  
 I want to receive free 2-Day delivery when my order exceeds the spending threshold  
 so that I receive additional value on larger purchases.

### **Acceptance Criteria**

* Cart \> $200 qualifies.  
* 2-Day Delivery cost becomes $0.  
* Threshold is configurable.
